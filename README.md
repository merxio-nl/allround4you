# ALLROUND4YOU Bouw & Service

Responsive static client-review website built with HTML, CSS and JavaScript.

## Local preview
1. Open this project folder in Visual Studio Code.
2. Open `index.html`.
3. Start Live Server with **Go Live**.
4. Check the site at `http://127.0.0.1:5500`.

## Structure
- `index.html` — page content and sections.
- `css/style.css` — visual design and responsive layout.
- `js/main.js` — mobile navigation and gallery lightbox.
- `img/` — logo, hero image and portfolio images.
- `CLAUDE.md` — mandatory rules for AI-assisted changes.
- `CHANGELOG.md` — stable version history.
- `TODO.md` — confirmed outstanding tasks.

## Publishing through GitHub Pages
1. Push the project to the repository `main` branch.
2. Open **Settings -> Pages** in GitHub.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`.
5. Save and wait for the deployment URL.
6. Test the published version on desktop and mobile before sharing it.
